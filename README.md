### 1.2 ใช้งานบน Google Colab

1. กด **Open in Colab** ด้านบน แล้วเชื่อมต่อ runtime
2. ตรวจแหล่งที่มาหาก Colab ถามยืนยันการรัน notebook
3. รันเซลล์ **เตรียมข้อมูลอัตโนมัติ** ก่อนเริ่มบทที่ 1 หรือเลือก **Runtime → Run all** เพื่อรันโค้ดตัวอย่างทั้งหมด
4. รอข้อความที่ขึ้นต้นด้วย <code>พร้อมเรียน: ตรวจภาพครบ 16 ไฟล์</code>
5. อ่านแต่ละบท ส่ง Prompt ตัวอย่างให้ AI ทดลอง รันโค้ด และทำแบบฝึกหัดในเซลล์ที่เว้นไว้

Colab เปิดไฟล์ notebook จาก GitHub โดยไม่ได้คัดลอกโฟลเดอร์ <code>dataset/</code> มาด้วย เซลล์เตรียมข้อมูลจึงดาวน์โหลดภาพจาก repository และตรวจ SHA-256 ก่อนใช้ เมื่อเปลี่ยนหรือรีเซ็ต runtime ให้รันเซลล์นี้อีกครั้ง

### 1.3 ใช้งานด้วย Jupyter บนเครื่อง

เปิด terminal ในโฟลเดอร์ repository แล้วติดตั้งเครื่องมือที่จำเป็นสำหรับการเปิด notebook:

~~~bash
python3 -m pip install notebook opencv-python-headless numpy matplotlib
python3 -m notebook Computer_Vision_AI_Workshop.ipynb
~~~

รันเซลล์เตรียมข้อมูลก่อนเริ่มบทเรียนเช่นกัน หากภาพใน <code>dataset/</code> ตรงกับค่า SHA-256 ใน notebook ระบบจะใช้ไฟล์ในเครื่องโดยไม่ดาวน์โหลดซ้ำ ภาพประกอบ Markdown ใน notebook ยังอ้าง URL ของ GitHub จึงต้องมีอินเทอร์เน็ตเพื่อให้แสดงครบ

### 1.4 ตรวจว่าพร้อมเรียน

เมื่อเตรียมข้อมูลสำเร็จ จะเห็นข้อความลักษณะนี้:

~~~text
พร้อมเรียน: ตรวจภาพครบ 16 ไฟล์ (ดาวน์โหลดใหม่ N ไฟล์)
โฟลเดอร์ทำงาน: ...
ตัวอย่างเส้นทาง: dataset/butterfly.jpg — รันตัวอย่างในบทเรียนต่อได้เลย
~~~

ค่า <code>N</code> คือจำนวนไฟล์ที่เพิ่งดาวน์โหลด หากเป็น <code>0</code> หมายถึงภาพที่มีอยู่ผ่านการตรวจทั้งหมดแล้ว ทุกตัวอย่างใช้ path รูปแบบ <code>dataset/ชื่อไฟล์</code> โดยไม่ต้อง mount Drive หรือเปลี่ยน working directory

## 4. โครงสร้างหลักสูตร

| บท | หัวข้อ | ตัวอย่างที่รันได้ | แบบฝึกหัด |
|:--:|:--|:--|:--|
| 1 | ภาพดิจิทัลและระบบสี | แยก B, G, R และเทียบ Grayscale | ปรับภาพผีเสื้อเป็นโทนอุ่นหรือโทนเย็น |
| 2 | การเลือกพื้นที่ด้วยความสว่าง | เทียบ Threshold 50, 100 และ 210 | สร้าง Mask ให้เหลือแท่งกลาง |
| 3 | Threshold แต่ละประเภท | เทียบ Binary, Binary inverse, Trunc และ To zero ทั้งสองแบบ | เก็บแท่งมืดโดยรักษาค่าเทาเดิม |
| 4 | การเลือกวัตถุด้วยสี | ใช้ HSV เลือกวัตถุและเปลี่ยนสีเฉพาะพื้นที่ | เลือกสองสีและกำหนดสีเน้นเอง |
| 5 | การแปลงตำแหน่งและรูปทรง | เลื่อน ย่อ หมุน และ Shear ในกรอบภาพ | ย่อและจัดวางวัตถุโดยไม่ตัดออกจากกรอบ |
| 6 | Affine Transformation | เปลี่ยนสี่เหลี่ยมด้านขนานเป็นจัตุรัสด้วยจุดสามคู่ | ออกแบบป้ายกว้างเป็นสองเท่าของสูง |
| 7 | Perspective Transformation | แก้มุมกล้องของปกหนังสือด้วยจุดสี่คู่ | แก้ปกแล้วเพิ่มขอบตามขนาดที่เลือก |
| 8 | การเลือกพื้นที่และปรับขนาดภาพ | Crop ลูกบอล เติมขอบ และ Resize โดยคงสัดส่วน | ทำภาพลูกบอลแนวนอน 400 × 300 พิกเซล |

**ลำดับการเรียนในแต่ละบท:** อ่านหลักการ → ลองส่ง Prompt ตัวอย่างให้ AI → รันและเทียบกับโค้ดตัวอย่าง → ทำแบบฝึกหัดเอง → ตรวจภาพและแนวทางเฉลยท้าย notebook

## 5. แนวคิดที่ควรรู้

| แนวคิด | ความหมายในบทเรียน | จุดที่มักสับสน |
|:--|:--|:--|
| **BGR กับ RGB** | OpenCV อ่านภาพสีเป็น BGR ส่วน Matplotlib แสดงภาพสีตาม RGB | ส่งภาพ BGR ให้ Matplotlib ตรง ๆ แล้วสีสลับ |
| **Grayscale กับ Binary Mask** | Grayscale มีระดับความสว่างหลายค่า; Mask บอกพื้นที่ที่เลือก | ภาพเทาไม่ได้แปลว่าเป็น Mask |
| **Threshold กับ HSV** | Threshold ใช้ความสว่าง; HSV ใช้ช่วงสี ความอิ่มสี และความสว่าง | เลือกวัตถุสีด้วยค่าเทาอย่างเดียวอาจเลือกพื้นหลังติดมา |
| **พิกัดภาพ** | จุดกำเนิดอยู่มุมซ้ายบน; x เพิ่มทางขวา y เพิ่มลงล่าง | สลับ x/y หรือเรียงมุมผิด |
| **Affine กับ Perspective** | Affine ใช้จุดสามคู่และรักษาเส้นขนาน; Perspective ใช้จุดสี่คู่เพื่อแก้มุมมอง | หมุนภาพอย่างเดียวแก้การบิดจากมุมกล้องไม่ได้ |
| **Crop, Resize และการเติมขอบ** | Crop เลือกพื้นที่; Resize เปลี่ยนขนาด; เติมขอบช่วยรักษาสัดส่วน | Resize โดยไม่รักษาสัดส่วนทำให้วัตถุยืด |
| **ภาพโปร่งใส** | PNG บางภาพมี alpha channel และตัวอย่างวางบนพื้นขาวก่อนประมวลผล | อ่านเป็นภาพ 3 ช่องหรือแสดงบนพื้นดำแล้วได้ผลต่างจากตัวอย่าง |

## 6. แนวทางเรียนและสอน

### 6.1 สำหรับผู้เรียน

1. อ่าน **วัตถุประสงค์** และดูภาพประกอบของบทนั้น
2. ส่ง **Prompt ตัวอย่าง** ให้ AI แล้วอ่านโค้ดที่ได้ โดยตรวจชื่อไฟล์ พิกัด ค่า Threshold และขนาดภาพ
3. รันโค้ดตัวอย่างที่เตรียมไว้เพื่อเห็นผลอ้างอิง หากโค้ดจาก AI ต่างออกไป ให้เทียบภาพและเหตุผล
4. ทำ **แบบฝึกหัด** ในเซลล์ที่เว้นว่าง เลือกค่าหรือวิธีของตนเอง และบันทึก Prompt ที่ใช้
5. เทียบผลกับเกณฑ์โจทย์และแนวทางเฉลยท้าย notebook

ตัวอย่างรูปแบบ Prompt ที่ใช้ต่อยอด:

~~~text
สร้างโค้ด Python สำหรับ Google Colab/Jupyter Notebook
อ่านภาพ [ชื่อไฟล์] จาก dataset/
ทำ [เป้าหมาย] ด้วย [วิธีและค่าที่เลือก]
แสดงภาพก่อน/หลัง พร้อมบอกค่าที่ใช้
ตอบเป็นโค้ด 1 เซลล์ที่อ่านง่าย แล้วอธิบายผลสั้น ๆ
~~~

ให้ใช้ชื่อไฟล์จริงจาก [บัญชีภาพ](#images) และระบุค่าพิกัดเป็นพิกเซล เมื่อผลไม่ตรง ให้ส่งข้อความ error หรือภาพผลลัพธ์กลับไปแก้ Prompt ทีละประเด็น

## 9. การปรับใช้

### 9.1 เปลี่ยนชื่อ repository หรือ branch

ในเซลล์เตรียมข้อมูลของ notebook ให้แก้ <code>REPO</code> และ <code>BRANCH</code> จากนั้นแก้ URL ภาพทั้งหมดที่ชี้ไป <code>raw.githubusercontent.com</code> รวมถึงลิงก์ Colab ใน notebook และ README ให้ตรงกัน ภาพประกอบจะไม่เปลี่ยนตามค่า <code>REPO</code> ในโค้ดโดยอัตโนมัติ เพราะ URL ถูกเขียนไว้ในเซลล์ Markdown

### 9.2 เปลี่ยนภาพในชุดฝึก

1. ตรวจสิทธิของภาพใหม่ก่อนนำเข้า repository
2. ปรับรายการชื่อไฟล์และค่า <code>EXPECTED_SHA256</code> ในเซลล์เตรียมข้อมูล
3. ตรวจทุก Prompt และโค้ดที่ใช้ชื่อไฟล์ พิกัด ช่วงสี และขนาดภาพเดิม
4. สร้างภาพผลลัพธ์ใน <code>assets/notebook/</code> ใหม่ แล้วแก้คำอธิบายที่เกี่ยวข้อง
5. ทดสอบจาก runtime ใหม่เพื่อให้แน่ใจว่าไม่ได้ใช้ไฟล์เก่าที่ค้างอยู่

การเผยแพร่ฉบับดัดแปลงหรือการนำไปใช้สอนต้องเป็นไปตาม [LICENSE](LICENSE) และสิทธิของเจ้าของภาพแต่ละรายการ
